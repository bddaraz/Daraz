Easy Shop website files (Bangla)
- index.html: storefront
- details.html: product details
- admin.html: product admin and store customization form

Admin can edit product information and store name, announcement, hero text, colors, banner image URL/link and contact details. Data is saved in localStorage for the same browser/device only. This demo has no secure admin login and does not sync changes to customers. For a live shop, connect secure authentication and a shared database/backend.


## নতুন অ্যাডমিন সুবিধা
- প্রতিটি পণ্যের জন্য আলাদা “বিস্তারিত দেখুন” URL দিতে পারবেন। ফাঁকা রাখলে সাইটের নিজস্ব পণ্যের বিস্তারিত পৃষ্ঠা খুলবে।
- প্রতিটি পণ্যের জন্য আলাদা Buy Now URL দিতে পারবেন। লিংক দিলে বাইরের কেনাকাটার পৃষ্ঠা খুলবে; ফাঁকা রাখলে ডেমো কার্টে যোগ হবে।
- এই সংস্করণও localStorage-ভিত্তিক ডেমো; লাইভ সাইটে সব ভিজিটরের জন্য তথ্য শেয়ার করতে অনলাইন ডেটাবেস লাগবে।
